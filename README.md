# Central de estaciones meteorológicas_Sistemas de Comunicaciones_07
## Proyecto de Sistemas de Comunicaciones, grupo 07, 2027-1

---

### Definición del proyecto

Creación de una central de estaciones meteorológicas con microcontroladores ESP32, mediante el uso del protocolo de comunicación ESP-NOW y sensores de temperatura y humedad DHT11.
